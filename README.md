# R & B 💜

A Wordle-style word game for two, played as a Telegram Mini App.

One player sets a secret five-letter word, and the other gets six guesses to find it. Then you swap. The first to 30 points wins the round.

## Rules
- Points for solving: 6 for 1 guess, 5 for 2, and so on down to 1 for 6 guesses.
- If the guesser misses, the setter gets +2 for stumping them.
- A hint reveals one letter and costs 1 point.
- When you set a word, you can add a clue or tap **Surprise me** for a random word with an automatic clue.
- After each result, you can send a taunt along with your next word.

## How it works
There's no server and no database. Each turn's game state travels inside the link you send, lightly scrambled so the secret word isn't readable. Scores and history are saved on each phone.

## Files
- `index.html` — the page with all five screens
- `css/style.css` — the purple-to-pink look
- `js/app.js` — game logic
- `js/answers.js` — words for "Surprise me", each with a clue (add your own!)
- `js/valid.js` — every five-letter word accepted as a guess (generated by `npm run build`, which Vercel runs automatically)
- `js/config.js` — your bot settings and game rules

## Going live
1. **Vercel**: import this repo at vercel.com/new, keep the default settings and click Deploy. You'll get a link like `https://r-and-b.vercel.app`.
2. **Bot**: in Telegram, message @BotFather and send `/newbot`, then pick a name and username.
3. **Mini App**: in @BotFather, send `/newapp`, choose your bot, paste your Vercel link, and give it a short name such as `play`.
4. **Config**: in `js/config.js`, set `BOT_USERNAME` and `APP_SHORT_NAME`, then commit. Vercel redeploys automatically.
5. Open `https://t.me/<your_bot>/<short_name>`, start a game, and send the word to your partner.
